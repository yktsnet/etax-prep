## Guarantees

### 1. `tests/aggregate.test.mjs` — core/aggregate.mjs (applied / toJournal / effectiveEntries / assetLedger / consumptionTax / accruals / monthlyMatrix / revenueByMonth / salaryForYear)

- `applied` は額面に家事按分率を掛けた額を返す
- `applied` は取消済みの取引を 0 として扱う
- `toJournal` は費用の借方に勘定科目を、貸方に事業主借を置く
- `toJournal` は売上の貸方に勘定科目を、借方に事業主貸を置く
- `toJournal` が生成する金額は按分後の額である
- `effectiveEntries` は一括償却の資産を取得年から3年間、取得価額の3分の1ずつ費用として展開する
- `effectiveEntries` は一括償却の4年目に何も計上しない
- `effectiveEntries` は一括償却の2年目以降について、計上日を当年の同月同日へ振り替える
- `effectiveEntries` は少額特例の資産を取得年に全額計上し、翌年以降は計上しない
- `assetLedger` は取消済みの資産を台帳に含めない
- `consumptionTax` は税込金額から内税を割り戻し、免税・2割特例・本則の3方式の納付額を返す
- `consumptionTax` は税率区分が対象外の取引を売上税額に含めない
- `consumptionTax` は仕入税額を家事按分後の金額から算出する
- `consumptionTax` は軽減税率 8% も税込から割り戻す
- `consumptionTax` は取消済みの取引を集計に含めない
- `accruals` は未収と未払を区分ごとに集計し、対象の取引一覧を返す
- `accruals` は区分を持たない通常の取引を対象に含めない
- `monthlyMatrix` は指定年の費用のみを、按分後の額で勘定科目×月に集計する
- `revenueByMonth` は指定年の売上を月別に集計する
- `salaryForYear` は適用開始年月の履歴から、各月に有効な月額を引く
- `salaryForYear` は適用開始年月より前の月に給与を計上しない

### 2. `tests/tax.test.mjs` — core/tax.mjs (salaryDeduction / salaryIncome / estimate)

- `salaryDeduction` は収入が低い場合に下限額を下回らない

- `salaryDeduction` は高収入帯で上限額を超えない
- `salaryDeduction` は最低保障額が適用される収入帯で定額を返す
- `salaryIncome` は給与収入から給与所得控除を引いた額を返す
- `basicDeduction` は合計所得金額の帯に応じた基礎控除額を返す
- `basicDeduction` は高所得帯で額を逓減させ、最上帯では 0 を返す
- `estimate` は住民税の基礎控除に所得税とは別の額を使う
- `estimate` は事業所得と給与所得を合算し、所得控除と基礎控除を引いて課税所得を出す
- `estimate` が返す課税所得は 1000 円未満を切り捨てた値である
- `estimate` が返す所得税には復興特別所得税が上乗せされている
- `estimate` は事業所得が赤字のとき給与所得と損益通算し、課税所得と税額を減らす
- `estimate` が返す住民税には、所得割に加えて均等割と森林環境税が定額で乗る
- `estimate` が返す限界税率は、所得税率・住民税率・復興特別所得税の合計である
- `estimate` は源泉徴収税額が算出税額を上回るとき、差引を負値（還付）で返す
- `estimate` は所得が控除に満たない場合でも、課税所得と所得税を負値にしない

## Gaps

以下は契約面だが、対応するテストが無い。見送った理由も併記する。

- 保存先（`LocalStore` / `GitHubStore`）が同一のインターフェース契約を満たすことが未保証。`GitHubStore` の失敗時の扱いは 4 で押さえたが、両実装の等価性は別問題として残る。とくに日付変更で所属月をまたぐ更新は両実装が別々に持つ分岐であり、片方だけ壊れうる。GitHub API の fake が要り、棚卸しの範囲を超えるため見送った
- 資産の判定しきい値（10万・30万）が未保証。判定が UI 側（`public/app.js`）にあり、`core/` へ切り出さないとテストできない。実装の移動を伴うため見送った

## About

対象は `core/` の純関数（集計・税計算）と HTTP API の応答契約。UI（`public/`）の見た目と操作は対象外で、user の目視検証に回す。**ここに載っていない振る舞いは約束ではなく、予告なく変わりうる。** 地位は設計判断の記録と同格。
