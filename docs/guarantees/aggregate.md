# aggregate

## 按分と仕訳

| 保証 | 対応テスト |
|---|---|
| `applied` は額面に家事按分率を掛けた額を返す | `按分率を掛けた額が計上される` |
| `applied` は取消済みの取引を 0 として扱う | `取消された取引は0として扱う` |
| `toJournal` は費用の借方に勘定科目を、貸方に事業主借を置く | `費用の貸方は事業主借に固定される` |
| `toJournal` は売上の貸方に勘定科目を、借方に事業主貸を置く | `売上の貸方は売上高、借方は事業主貸になる` |
| `toJournal` が生成する金額は按分後の額である | `費用の貸方は事業主借に固定される` |

## 資産の費用化

| 保証 | 対応テスト |
|---|---|
| `effectiveEntries` は一括償却の資産を取得年から3年間、取得価額の3分の1ずつ費用として展開する | `一括償却は取得年から3年均等で費用化し、4年目には残らない` |
| `effectiveEntries` は一括償却の4年目に何も計上しない | `一括償却は取得年から3年均等で費用化し、4年目には残らない` |
| `effectiveEntries` は一括償却の2年目以降について、計上日を当年の同月同日へ振り替える | `一括償却の2年目以降は当年の日付へ振り替わる` |
| `effectiveEntries` は少額特例の資産を取得年に全額計上する | `少額特例は取得年に全額、翌年には残らない` |
| `effectiveEntries` は少額特例の資産を取得の翌年以降に計上しない | `少額特例は取得年に全額、翌年には残らない` |
| `assetLedger` は取消済みの資産を台帳に含めない | `取消された資産は台帳に載らない` |

## 消費税

| 保証 | 対応テスト |
|---|---|
| `consumptionTax` は税込金額から内税を割り戻して売上税額と仕入税額を出す | `消費税は税込から割り戻し、免税・2割特例・本則の3通りを出す` |
| `consumptionTax` は免税・2割特例・本則の3方式の納付額を返す | `消費税は税込から割り戻し、免税・2割特例・本則の3通りを出す` |
| `consumptionTax` は税率区分が対象外の取引を売上税額に含めない | `対象外の税率区分は消費税に含めない` |
| `consumptionTax` は仕入税額を家事按分後の金額から算出する | `仕入税額は按分後の金額から求める` |
| `consumptionTax` は軽減税率 8% も税込から割り戻す | `軽減税率8%も税込から割り戻す` |
| `consumptionTax` は取消済みの取引を集計に含めない | `取消された取引は消費税の集計に入らない` |

## 年末のまたぎ・月別の集計

| 保証 | 対応テスト |
|---|---|
| `accruals` は未収と未払を区分ごとに集計する | `またぎの未収・未払を区分ごとに集計する` |
| `accruals` は対象の取引一覧を返す | `またぎの未収・未払を区分ごとに集計する` |
| `accruals` は区分が無い通常の取引を対象に含めない | `またぎの未収・未払を区分ごとに集計する` |
| `monthlyMatrix` は取引を勘定科目×月に集計する | `科目×月は按分後の額で、指定年だけを集計する` |
| `monthlyMatrix` が集計する額は按分後の額である | `科目×月は按分後の額で、指定年だけを集計する` |
| `monthlyMatrix` は指定年以外の取引を集計に含めない | `科目×月は按分後の額で、指定年だけを集計する` |
| `revenueByMonth` は売上を月別に集計する | `売上は月別に積み上がる` |
| `salaryForYear` は適用開始年月の履歴から、各月に有効な月額を取り出す | `給与は適用開始年月の履歴からその月に有効な額を引く` |
| `salaryForYear` は適用開始年月より前の月に給与を計上しない | `適用開始前の月は給与が立たない` |
