# api

## 取引の登録

| 保証 | 対応テスト |
|---|---|
| 存在しない勘定科目を指定した登録は 400 を返す | `存在しない勘定科目での登録は400を返す` |
| 金額が無い、0、負値の登録は 400 を返す | `金額が無い、または0以下の登録は400を返す` |
| 登録時に勘定科目マスタの既定按分率と税率区分を補完する | `登録時に勘定科目マスタの既定按分率と税率区分が補完される` |
| 明示された按分率と税率区分は既定より優先される | `明示した按分率と税率区分は既定より優先される` |
| 日付を省略した登録は当日の日付で記録される | `日付を省略すると当日で登録される` |

## 存在しない対象への要求

| 保証 | 対応テスト |
|---|---|
| 存在しない取引への更新は 404 を返す | `存在しない取引の更新は404を返す` |
| 存在しない証憑の取得は 404 を返す | `存在しない証憑の取得は404を返す` |
| 未知の経路は 404 を返す | `未知の経路は404を返す` |

## 取消・取り外しと集計

| 保証 | 対応テスト |
|---|---|
| 取消した取引は集計から外れる | `取消しても取引は残り、集計からだけ外れる` |
| 取消した取引は保存先に残り続ける | `取消しても取引は残り、集計からだけ外れる` |
| 証憑を取り外すと、取引からの紐付けだけが外れる | `証憑を取り外しても紐付けが外れるだけで、ファイルは残る` |
| 取り外した証憑は退避先に記録が残る | `証憑を取り外しても紐付けが外れるだけで、ファイルは残る` |
| 取り外した証憑のファイル自体は取得できる | `証憑を取り外しても紐付けが外れるだけで、ファイルは残る` |
| ダッシュボードは年を指定して集計できる | `ダッシュボードは年を指定して集計できる` |
