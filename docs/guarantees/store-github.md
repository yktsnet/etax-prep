# store-github

| 保証 | 対応テスト |
|---|---|
| `listEntries` は対象が無いとき（404）に空の一覧を返す | `取得の404は「まだ無い」として扱う` |
| `readReceipt` は対象が無いとき（404）に null を返す | `取得の404は「まだ無い」として扱う` |
| `addEntry` は書き込みが 404 で拒まれたとき例外を投げる（保存できていないのに成功として返さない） | `書き込みの404は握り潰さず例外にする` |
| `saveReceipt` は書き込み失敗を例外にする | `証憑の保存も書き込み失敗を例外にする` |
| `saveSettings` は書き込み失敗を例外にする | `設定の保存も書き込み失敗を例外にする` |
| `GitHubStore` はトークンが欠けていれば生成時にエラーになる | `トークンとリポジトリが無ければ生成時に落とす` |
| `GitHubStore` はリポジトリが欠けていれば生成時にエラーになる | `トークンとリポジトリが無ければ生成時に落とす` |
| `readReceipt` は Contents API が content を返さない大きさ（1MB 超）の証憑も、raw で取り直して中身を返す | `1MB を超える証憑は raw で取り直して中身を返す` |
