# tax

## 給与所得控除と給与所得

| 保証 | 対応テスト |
|---|---|
| `salaryDeduction` は収入が低い場合に下限額を下回らない | `給与所得控除には下限がある` |
| `salaryDeduction` は収入帯ごとの計算式に従う | `給与所得控除は収入帯ごとの式で決まる` |
| `salaryDeduction` は高収入帯で上限額を超えない | `給与所得控除には上限がある` |
| `salaryDeduction` は最低保障額が適用される収入帯で定額を返す | `給与収入190万円までの給与所得控除は定額` |
| `salaryIncome` は給与収入から給与所得控除を引いた額を返す | `給与所得は収入から控除を引いた額` |

## 基礎控除

| 保証 | 対応テスト |
|---|---|
| `basicDeduction` は合計所得金額の帯に応じた基礎控除額を返す | `基礎控除は合計所得金額の帯で変わる` |
| `basicDeduction` は高所得帯で額を逓減させる | `基礎控除は高所得帯で逓減し0になる` |
| `basicDeduction` は最上帯で 0 を返す | `基礎控除は高所得帯で逓減し0になる` |
| `estimate` は住民税の基礎控除に所得税とは別の額を使う | `住民税の基礎控除は所得税と別の額を使う` |

## 課税所得

| 保証 | 対応テスト |
|---|---|
| `estimate` は合計所得金額から所得控除と基礎控除を引いて課税所得を出す | `事業所得と給与所得を合算して課税所得を出す` |
| `estimate` が返す課税所得は 1000 円未満を切り捨てた値である | `課税所得は1000円未満を切り捨てる` |
| `estimate` は赤字の事業所得を給与所得と損益通算する（課税所得と税額が事業所得 0 のときより小さくなる） | `事業が赤字なら給与所得と損益通算される` |
| `estimate` は所得が控除に満たない場合でも、課税所得を負値にしない | `所得が控除に満たなくても課税所得と税額は負にならない` |

## 税額

| 保証 | 対応テスト |
|---|---|
| `estimate` が返す所得税には復興特別所得税が上乗せされている | `所得税に復興特別所得税が上乗せされる` |
| `estimate` が返す住民税には、所得割とは別に、均等割と森林環境税が定額で加算される | `住民税には均等割と森林環境税が定額で乗る` |
| `estimate` が返す限界税率は、所得税率・住民税率・復興特別所得税の合計である | `限界税率は所得税・住民税・復興特別所得税の合計` |
| `estimate` は源泉徴収税額が算出税額を上回るとき、差引を負値（還付）で返す | `源泉徴収済みが税額を上回れば還付になる` |
| `estimate` は所得が控除に満たない場合でも、所得税を負値にしない | `所得が控除に満たなくても課税所得と税額は負にならない` |
